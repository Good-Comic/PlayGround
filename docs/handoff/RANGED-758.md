## 共鳴弦命中計數 / Resonant Strings impact counting

**繁體中文：** 延續同一 Owner 任務：卡牌標示每五次遠程命中連鎖，但原程式在投射物落點讀取攻擊者「目前射擊數」；多枚在途箭矢可因同一射擊數重複觸發，也可能因連弩架額外箭矢而錯過第五次實際命中。現在每個符合條件的遠程單位在有效投射物命中時累計，包含額外箭矢；目標已死亡而失效的飛行物不計入。每五次沿用原連鎖目標、範圍與傷害。計數隨單位存檔；舊存檔沒有該欄位，會從零開始，不推測先前命中數。沒有新增 RNG 或更改其他卡牌數值。

正式本地構建應用 `f8bc340582c8ba92c0d4600f5061375e7a818c52` 與基底在 Chromium 均通過 127 資源雜湊。固定種子受控場景以實際介面選擇連弩架及共鳴弦，原生右鍵攻擊：第四次攻擊產生第五次有效命中，新版附近敵人受到一次連鎖，基底尚未連鎖。`ranged-758-evidence/resonant-*` 保存截圖及結果；程式包裝只記錄傷害呼叫，沒有替換結算。Node 測試重現基底在途箭矢重複連鎖，並確認有效命中、死目標不計、讀檔保留計數，以及破片彈、遠程、恩賜存檔和 RNG 回歸。自然波次與完整戰役仍未驗證。

**English:** Continuing the same owned task, the card specifies a chain every five ranged hits, but the original code read the attacker's current shot count on impact. Multiple in-flight arrows could repeatedly trigger on one shot count, or Linked Bolt's extra arrow could make it miss the fifth actual impact. Each eligible ranged unit now counts valid projectile impacts, including bonus arrows; projectiles invalidated by a dead target do not count. Every fifth impact uses the existing chain targets, range and damage. The per-unit count is saved; older saves lack it and restart from zero instead of guessing prior hits. No RNG or other card values were added or changed.

Official local application build `f8bc340582c8ba92c0d4600f5061375e7a818c52` and baseline each verified 127 resources in Chromium. In a fixed-seed controlled scene, Linked Bolt Rack and Resonant Strings were selected in the actual interface and a native right-click ordered an attack. The fourth attack produced the fifth valid impact: the new version chained once to a nearby enemy, while baseline had not chained yet. Screenshots and results are under `ranged-758-evidence/resonant-*`; a wrapper recorded damage calls without replacing resolution. Node cases reproduced baseline's repeated chains with in-flight arrows and verified valid hit counts, dead-target exclusion and save/load, with Fragment Shells, ranged-boon, boon-save and RNG regressions. Natural waves and the full campaign remain unverified.
