The GDD specifies a 15-second pause for lowland farms during floods without building destruction. Previously the event announced and marked flooding but farms continued producing, timing used wall clock and farm state was not saved. Using the existing lowland heuristic (farm y greater than base y plus 5), affected farms now pause for 15 simulation seconds, remain paused while the game is paused, retain remaining time on reload and resume afterward; a water overlay makes the pause visible. Farm rate, map generation, collision and RNG are unchanged. This preserves the existing coordinate heuristic and marks only farms present when the event starts; it does not claim a heightmap or full natural flood acceptance. Legacy saves without `flooded` load farms as unflooded.
