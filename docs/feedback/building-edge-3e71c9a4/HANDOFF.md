Renderer.drawBuilding原本在建築中心超出畫面250像素便略過，但建築與旗幟、煙柱會隨鏡頭放大。正式縮放1.6的城心錨點在256高Canvas下方261像素時，仍有2224個非透明像素應可見，舊版卻全數略過。

js/renderer.js將既有餘裕改為250×max(1,zoom)。放大時同步保留建築上緣；縮小及1倍時的界線完全不變。仍剔除真正遠離畫面的建築。沒有修改建築幾何、文明美術、動畫、碰撞、視野、費用、傷害、RNG或模擬資料。
