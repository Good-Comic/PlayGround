# 廢工坊：限時攻城支援內部原型

本回報依使用者最新語言指示採臺灣正體中文，遊戲介面保留四語。

## 實際新增玩法

在救援遠征之外新增獨立的廢工坊信號。英雄必須實際抵達，玩家再決定是否花80木材，二選一借用一輛投石車或衝車。每局一次，從領取時起算30個遊戲模擬秒；仍占正式軍事人口，含佇列不足時不扣款。試用不解鎖科技或永久生產權限，不更動單位既有傷害、射程、生命或文明加成。

這提供「保留木材建設／購買短期火力」與領取時機的選擇。備戰中會明示倒數立即開始，可先到工坊等交戰前夕再付款；不擅自延長30秒以製造通過。借用後會退出英雄直控、取消舊落點並選取攻城單位，保留上一輪F2／英雄操控改善。

位置沿用不消耗模擬 RNG 的確定性放置，與救援點至少分開6格；這是原型放置預設，非GDD聲稱已明訂的距離。信號只提供任務位置，不揭露地形或敵軍。試用單位使用既有原生 spawn、人口、彈道與 expireIn，期限會被暫停／選卡／結算凍結，並保存在原生存檔中。到期使用既有離隊／死亡統計流程，沒有另造退款或永久留兵規則。

## 真實設計阻塞

GDD `docs/gdd/issue-8-snapshot.md:174` 同時規定「廢工坊花80W換一次通用攻城試用30秒」與「每局獎勵總值上限180」，但未定義限時單位的獎勵估值。

已向使用者提出：限時試用是否不列永久獎勵額度，或救援／工坊每局只能擇一領取。**尚未收到答覆，沒有擅自採用任一選項。** 當前可操作原型允許各自試驗兩種事件，尚未實裝180總獎勵帳，因此是 PLAYTEST-EXPERIMENTAL；正式多POI整合為 SPEC_DECISION_REQUIRED，不能標記READY或公開發布。商旅與完整三處分配仍未完成。
