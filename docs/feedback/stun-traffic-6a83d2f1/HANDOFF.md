# 完全暈眩後交通殘留修正

本輪實際修正：單位完全暈眩而跳過AI／移動更新時，清除舊 `_heading`、`_yieldTo`，並重設 `_trafficPriority`。原本只清除移動進度，留下舊朝向；附近同隊因而把停止單位誤判為迎面行軍，實際倒退讓行。此修正與現有「停止移動清除交通意圖」規則一致，不取消物理身體碰撞，不改任何攻擊或暈眩數值。

## 正式機制與缺陷

現有attackUnit明確實作西班牙玩家村民每8秒首擊非Boss敵軍，造成0.5模擬秒完全暈眩。既有tests/spa-stun.test.mjs覆蓋此正式規則，本輪不修改其持續時間、冷卻、傷害、陣營限制、Boss排除或部分減速。

正式兵種與原始種子42地圖建立三單位場景：一名敵軍brute已真實向左走過，後方同隊brute正要向右接敵；西班牙村民合法攻擊並暈眩前者。原版前者完全不動，後者卻得到以它為anchor的四秒讓行租約而倒退。新版停止者朝向清除，後方首步向前，碰撞仍保留。

這是局部程式缺陷；**不是C-36原始城心繞行案例，也沒有證明C-36已修復**。未修改整體尋路演算法、讓行期間或部隊傷害。
