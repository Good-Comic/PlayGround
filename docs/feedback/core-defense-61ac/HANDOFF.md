# 援護城心：讓回防與集火更容易操作

依使用者最新語言指示，本回報使用臺灣正體中文。原始識別符、測試輸出與正式四語介面維持原文。

## 真正新增的操作

在作戰指揮列加入「援護城心」。玩家主動點擊時選取原有全軍，若有已看見、正在原生攻擊射程內攻擊城心的敵軍，就集火最近者；沒有合適攻城者時，沿用正式護衛指令保護城心。這是手動快捷操作，沒有增加自動回防政策、傷害、攻速、資源或新AI規則。

英雄與村民不加入全軍。退出英雄直控沿用原生F2流程；不改村民工作。已有軍隊手動命令會因這次明確操作被覆寫，之後玩家的新命令也能立即覆寫援護，系統不會定時搶回控制。城心受損時按鈕使用醒目邊框，依自己的建築生命顯示，不洩漏未看見敵軍的位置。

攻城距離直接沿用原生updateAttack對建築的unitRange−0.1規則；不以任意索敵倍率擴大追擊。只使用已可見目標與原生pickAt／issueCommand／issueTacticalCommand；被遮擋而無法正確命中時保留錯誤回饋，不強制修改目標或繞過迷霧。

點擊會取消尚未提交的拖線預覽，再下達指令。暫停、選卡、結算、施工及對話框時阻擋操作。Tab／Space／Enter保留原生按鈕行為，長按不重複下令。Save/Load沿用原生護衛目標ID，不另存一個會重新接管軍隊的自動控制器。

## 為何接續此切片

前一個正常法蘭克測試在第4波敗北，當時仍有20名戰鬥單位；影片顯示部隊集中在城心一側。這不是已確認的AI缺陷根因。本切片針對玩家已回報「被動、難以控制」改善操作入口，不把按鈕存在當成敗北已修復，也不擅改難度。

目前分支繼承拖曳戰線、翻轉前後、原生撤回重整、可擊破RALLY旗手及所有之前有效成果。旗手正式法蘭克第5波仍需正常流程驗證，前次第4波敗北證據保留在rally-carrier-61ac。
