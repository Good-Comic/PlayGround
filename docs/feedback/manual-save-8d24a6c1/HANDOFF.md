## 玩家實際差異

玩家手動訓練後，建築原有13模擬秒的手動優先期限；即使手動佇列已完成，總管在期限內仍不應搶先排隊。舊版snapshot已保存 `manualProductionUntil`，restore卻漏了該欄位，造成讀檔後狀態由「手動生產優先」變成「可生產」，可能提早自動扣款排隊。

`js/game.js` 的建築restore僅新增一個欄位：還原有限、非負的原期限，沒有重新計算或延長13秒。過期值仍過期，舊檔缺值／無效值維持undefined，不虛構新的保護時間。沒有改動總管排隊節奏、資源、兵種、隊列上限或英雄程式。
