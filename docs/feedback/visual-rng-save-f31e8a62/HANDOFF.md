## 相容性與狀態語義

沿用version1，舊存檔缺欄位時保留既有種子預設；非整數、負數、超過uint32、字串、null等無效值亦回預設。不為缺少狀態的舊存檔假造歷史。舊版程式可以忽略新選填欄位；降版讀取仍無法接續視覺序列。

儲存使用無符號32位元表示。內部mulberry32在抽樣後可能顯示signed數，restore則顯示unsigned；比較的是同一組位元與實際後續序列，不要求數字字面正負一致。前次暈眩案例現在現場-686357405／恢復3608609891，canonical皆3608609891，後續32值完全相同。

只接續**未來**視覺抽樣。既有飛散粒子、特效動畫等暫態仍不序列化；不能宣稱讀檔畫面逐像素相同，也沒有擴大存檔保存所有VFX實例。
