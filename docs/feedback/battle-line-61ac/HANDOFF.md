# 拖曳戰線與撤回重整

本輪依玩家「戰鬥被動、難控制」回饋，新增真實部隊編排與移動，沒有加攻擊、減傷、無敵、瞬移或額外資源。報告依使用者要求採臺灣正體中文，介面維持四語。切片完成後繼續下一個已批准戰鬥內容，不以Push作為結束條件。

## 玩家操作與實際效果

選取部隊後按F或點「戰線」，在戰場拖曳寬度，放開下令。步兵前排、遠程／攻城在後、有步兵時騎兵部署兩翼；單一兵種則自行排成戰線。未選戰士時使用全軍；不搶村民或英雄直控。

「進攻」使用原生攻擊移動，部隊沿途接敵；「移動」使用原生移動，可中斷交戰拉回重整。V翻轉前後，讓撤退時前排仍在朝敵軍的一側。右鍵／Esc取消，中鍵移鏡與滾輪沿用原操作。戰鬥持續進行；要凍結規劃，使用既有Shift+Space布令。

預覽以原生視野判斷落點資訊：已知受阻用叉號，未見落點灰色，不查詢隱藏障礙。已知無效戰線整批不下令；灰色落點仍可能在前進時發現障礙。既有尋路、碰撞、交戰與手動覆寫保持有效，不強制維持戰線或提供光環。

間距沿用commandMove的0.8，較大單位依原碰撞半徑加寬。進攻逐單位走原生戰術入口；同一手勢批次合併一次選取回報、指令音與旗標，避免200次UI／音效爆量，沒有跳過部隊命令或戰鬥機制。
