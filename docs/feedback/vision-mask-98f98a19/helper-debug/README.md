# 首輪斷言失敗與更正紀錄

首輪終端輸出的原始位元組未落盤，原始 bytes 不存在。此資料夾內標示 `reconstructed` 的檔案，是依目前對話中實際工具輸出與當時寫入內容重建，並非原始日誌封存；沒有重跑失敗版本來製造歷史證據。檔案中的耗時與堆疊行號保留當時工具顯示內容，不代表本輪測試。

- `first-default-output.reconstructed.txt`：首次 `node --test tests/vision-mask.test.mjs` 的工具輸出文字重建；exit code 為 1。
- `first-detailed-output.reconstructed.txt`：隨後 `node tests/vision-mask.test.mjs` 的實際工具輸出文字重建；14 項中 13 項通過，exit code 為 1。
- `original-case.reconstructed.mjs`：原始外環幾何生成式、AA 餘裕、原斷言與當時觀察值的重建。資料與斷言供查閱，沒有執行歷史斷言。

失敗分類是測試斷言期待問題。原配置有兩個重合的中心圓（半徑 1），八個外環圓中心距 1.8、半徑 1.1，`inset = 0.01`。原斷言要求最後恰留一個中心圓；實際保留兩個。保守 API 只承諾在證明覆蓋時省略，未承諾每個幾何冗餘圓都必須刪除。固定三層證明未觸發裁減仍可符合契約。

原本誤將預設測試的精簡失敗輸出與隔離模式聯想，已更正：沒有證據支持平台或 Node 隔離故障；當時的失敗由上述斷言造成。詳細輸出只用於顯示失敗內容。

目前測試檔保留兩個獨立案例：原外環配置允許保留一個或兩個中心來源，驗證獨立取樣聯集不變且中心不能全刪；外環中心距 1.6、半徑 1.2 的加大重疊配置另要求確實刪除一個中心，驗證逐筆刪除。原案例沒有消失；新案例也沒有取代它。取樣驗證是有限測試，並非完整幾何或 Canvas 像素證明。
