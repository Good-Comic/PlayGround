# 通用刀盾兵的有界向量影格快取

## 玩家可感受的變化

正式候選為通用militia增加惰性SVG影格快取，降低大量刀盾兵的重複SVG繪製成本。沒有更換服裝／文明身份、改動畫映射、傷害、射程、AI、碰撞、模擬時間或RNG。死亡動畫固定使用原圖，其他兵種與文明特殊圖集沿用原路徑。沒有公開部署。

`js/sprite-atlas.js` 只為militia descriptor啟用 `vectorFrameHash`，來源SHA-256鎖定24baa4cc550837041573999038d89265b4e81ec0b239c54837fd0ebd8417b1ee。額外來源抓取必須驗證該雜湊，再保留目標格附近兩格的原始SVG群組、建立64×64巢狀向量視窗。這不是任意SVG的通用安全裁剪規則，也不是先前像素不一致的位圖縮放快取；未修改原SVG資產。

目前僅支援前四列64個存活動作影格。每個圖集最多64格、不驅逐重複解碼，來源只抓取一次；單一解碼佇列利用閒置時間與50ms有限等待逐格前進。`js/renderer.js` 只有影格已解碼時才改用它，未準備好、hash／解碼失敗或死亡列均使用原圖。原正式構建完整性檢查未繞過。

## 保留的失敗及修正

初步單一NW行走影格保留一格鄰域，6組像素相同，內容約81KB→9.4KB；只是初步原型，不是最終鄰域或全面效能證據。拓展全圖集後，第4列第0格、DPR1、scale0.6出現6個RGBA通道差異。擴至兩格鄰域仍是相同失敗。因此沒有宣稱鄰域擴張已修好死亡列，也沒有放寬像素容差；死亡列改保留原圖。該差異的完整幾何／取樣根因未定，後續不得逕自把死亡列打開。

初版64格冷載入20秒仍未完成。3秒診斷確認來源hash正確、cache64、ready0、created Blob0，證明該受控200單位負載下閒置工作尚未執行。改為一次只處理一格、設有限等待的排程後，64格完成並全部釋放URL。失敗、診斷及中間成功結果均保存，沒有刪除歷史求PASS。

## 暖快取短ABBA

每種實際100／200名通用刀盾兵，原生F2全選，Game.update固定不前進。只切換前後drawSpriteAtlasUnit方法；A1/B1/B2/A2各1秒暖機＋3秒量測。同一Canvas／場景，原圖和向量影格都已解碼。這是靜止、單兵種、單一常用影格、DPR1的暖測，不是混合戰鬥或冷啟動認證。
