# 迎戰節奏與作戰鍵盤改善

報告語言依使用者最新要求，採臺灣正體中文；正式遊戲介面保留四語。此為獨立內部原型，沒有替換任何公開版本，也不代表整體遊戲已通過趣味性驗收。

## 玩家能實際使用的改善

- 備戰時新增「提前迎戰」：先查看提示，再明確確認；也可以繼續備戰。放棄剩餘採集、整軍與研發時間，換取更早接敵，沒有額外獎勵。
- 確認只呼叫既有 `startWave()`。不快轉模擬、不刷新冷卻、不發資源；敵軍數量、波次相對生成時刻、傷害、卡牌權重與獎勵保持原規則。不操作仍照原倒數開戰。
- 第一個點擊將焦點放在取消按鈕，連按 Enter 不會直接開戰。暫停、選卡、結算、放置、選單及對話框會取消未完成確認。新局、讀檔與跨波次不可使用舊確認。
- 修正作戰快捷列的真實鍵盤問題：Space 正常啟用軍隊動作，不再被全域暫停攔截；Tab 正常移動按鈕焦點，不再誤切英雄直控。原先未聚焦按鈕時的戰場快捷鍵保留。

## 已觀察到的玩法差異

以中國文明 NORMAL、種子 `WORKSHOP-TRIAL` 正常開局，透過滑鼠／鍵盤取消、暫停、派英雄旅行及支付80木領取投石車，再提前迎戰。首批8名敵軍約在第23.82模擬秒出現，此時投石車仍有19.32秒；預設45秒備戰加首批10秒生成延遲約為55秒。

玩家用全軍與攻擊移動實際下令，投石車在第33.96模擬秒以原生彈道命中，`applyDamage`記錄40傷害；當時城心3000HP。沒有注入單位、資源、時間或強制清敵，攔截器只記錄後照常執行。這是 `PLAYER_EARLY_CALL` 正常輸入驗證，不是預設時間自然十波，更不是真人覺得好玩的證明。影片38.24秒。

初測只等可見敵軍才落下攻擊移動，但敵軍當時未進視野，因此沒有下令；支援自然到期，記為 `INCONCLUSIVE_NO_TRIAL_DAMAGE`。同次腳本的 Escape 先取消待落點命令，並未開啟暫停，導致儲存按鈕等待失敗。修正腳本使用已知入口方向的正常落點，且確認暫停已開啟後才存檔；保留所有初測紀錄，不將腳本問題算成遊戲缺陷。

最後版 `a291cb4` 另跑新局中國文明 NORMAL、種子 `EARLY-RAID-CAMPAIGN`，開局由玩家提前迎戰，以實際滑鼠守護城心並使用原生標記／神盾。約第72.95模擬秒清除16名敵軍，城心3000HP；正常出現三張候選卡、點卡及領取後回到第二波備戰，下一波可重新確認／取消。沒有改敵軍生命、資源、時間或完成條件。此為正常輸入的提前迎戰第一波限定PASS，不是十波或預設倒數戰役。
