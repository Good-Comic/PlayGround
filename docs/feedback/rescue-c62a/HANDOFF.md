# 救援遠征：增加備戰與出城目標

依使用者最新指示，本報告採臺灣正體中文，介面仍保留四語。

## 本輪實際玩法

新增可選的「救援工人」遠征。戰場出現救援信號，玩家可派英雄沿原生尋路前往；英雄實際抵達才有兩名村民加入，並取得返回城心附近的原生移動命令。玩家可以利用備戰空檔探索，也能在交戰期間選擇派英雄離開防線；沒有延長備戰時間或降低敵軍數值。

獎勵來自 GDD `docs/gdd/issue-8-snapshot.md:174` 已批准的 +2 村民，遵守經濟人口及佇列上限。只有一個空位時先加入一名，剩餘救援保留。完成後不能重複領取；村民後續死亡也不重置獎勵。

這是第一個救援型探索切片，**不是三類／三處 POI 系統全部完成**。廢工坊80木、30秒攻城試用，以及商旅機制仍未接入。當前僅兩名村民，依正式單價50食物計算為100資源等值，沒有額外資源獎勵。

## 規則與安全邊界

- 位置採確定性幾何候選與原生尋路檢查，不消耗模擬 RNG；不重寫地圖生成。
- 救援信號是已知任務情報，繪在迷霧之上；不揭露地形、敵軍或改變任一方視野。
- 此原型採英雄距離2格內接應；12／14／16格位置候選與避開營地9格是可測試的放置預設，不是新增攻擊／視野／傷害數值，並非聲稱 GDD 已逐一定義這些距離。
- 村民使用正式單位、屬性、碰撞與人口計算；加入時的原生 spawn RNG 消耗照常，沒有額外抽卡 RNG。
- 暫停、選卡及結算不更新救援。舊存檔沒有此欄位時延後初始化；新局／NG+ 經原生 newRun 重設。
- 新工人從救援點走回城心，不傳送、不強制完成路徑；玩家可用正式命令重新指派他們。

沒有變更傷害、攻速、單位費用、卡池、敵軍 AI、波次或現有操作入口。未修改 main 分支、Pages、公開版、舊 Issues、OpenCode、Immutable Playtest Build、RC 或他人持有的 Feed。沒有公開部署。

## 交戰性能

同種子100／200初始總單位的受控原生交戰，1.5秒暖機後量測約8秒牆鐘時間，依序執行；AI、碰撞與 Canvas 繪圖皆保留，單位會正常死亡，不保證始終全數同屏。Chrome154／Linux／SwiftShader軟體繪圖；硬體背景沿用前輪雲端環境。

200單位P95由83.4到99.9ms，保留 **INCONCLUSIVE**，不宣稱性能通過或無退步；需要重複與實體GPU／長時間驗證。既有低FPS時鐘、嚴格完整Save/Load、自然十波與NG+、真人聽感及硬體缺口均保留。本輪未提升RC等級。
