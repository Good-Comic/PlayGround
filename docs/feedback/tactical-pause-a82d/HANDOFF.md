# 戰術暫停：分兵、集火與英雄協同

本輪針對玩家「戰鬥太被動、難以控制」的實測回饋，依GDD《issue-8-snapshot》§2.2已批准的暫停布令，加入能直接在戰場使用的規劃介面。依使用者最新要求，報告採臺灣正體中文；遊戲介面仍保留四語。

## 使用方式

按 Shift+Space，或點波次標題旁的小旗，進入「戰術布令」。一般暫停選單也有入口。遊戲模擬保持暫停，先選兵種／全軍／英雄或滑鼠框選，再選移動、進攻移動、集火或護衛，點戰場落點。可同時安排步兵守線、騎兵轉向、遠程後撤及英雄移動。

每單位保留最後一項布令；不同小隊的命令分開保留。地面虛線、序號與文字摘要顯示計畫。標記Q與神盾E可預排，恢復時才經原生施法介面消耗冷卻。標記仍選原生最近的可見敵人，介面會顯示預計目標，不暗改為滑鼠選定敵人。

「復原上一步」保留最近32次介面編輯，能復原分隊覆寫或清除計畫；這是介面記憶上限，不是戰鬥平衡數值。中鍵拖曳平移、滾輪縮放，沿用原本鏡頭邊界與倍率。英雄直控仍保有原生跟隨鏡頭限制。

點「執行並恢復」，各組命令在同一模擬時刻經既有指令入口下達。其後玩家新指令立刻優先，不會被背景重播。取消會清掉未下達計畫並回到一般暫停；新局、讀檔、選卡與結算不回放舊計畫。再次點入口不會誤清已編好的命令。

## 實際遊玩結果

中國文明NORMAL新局，種子 `TACTICAL-COMMAND`；使用原生開局單位、資源與自動總管，沒有注入單位、資源、時間、敵軍生命或完成條件。布令期間實際等待1.2秒，時間、RNG、資源、單位位置／狀態／冷卻及備戰倒數完全不動。恢復後軍隊執行攻擊移動、英雄依計畫移動，神盾才進入正式冷卻。

透過前輪已完成的提前迎戰接敵，再暫停安排集火與標記。恢復後指定敵軍受到原生彈道攻擊，記錄到7.7傷害，當時標記剩約4.97秒。讀檔後保留已下達的原生命令，未執行計畫不重播。約第88.11模擬秒清除16名敵軍，城心3000HP，正常進入第一波三選一獎勵。

這是正常輸入的提前迎戰／戰術暫停第一波限定PASS，不是預設倒數自然十波、自然NG+或真人趣味性驗收。完整流程來源7802a76；後續介面改善沒有改其原生回放入口。最後版另行用實際滑鼠驗證步兵與騎兵分隊、覆寫／復原、框選、中鍵移鏡、滾輪縮放及恢復後的不同命令。

## 失敗與修正證據

Node初測7PASS／2FAIL：一項是原本暫停仍允許鏡頭平滑縮放，另一項是測試點選了敵人的地面座標而非實際sprite身體；設定測試鏡頭停穩並使用原生座標轉換點身體後通過，沒有改戰鬥條件。原始輸出已無損gzip保留。

分兵初測失敗：第二個落點落在面板後方，點擊命中面板而非Canvas，沒有產生命令；保留groups初測與診斷。新增中鍵移鏡／滾輪操作後，玩家可正常將落點移到開放戰場，再下令。最後實測三次點擊均命中Canvas，沒有透視迷霧、搬動單位或偷偷呼叫布令函式取代滑鼠操作。
