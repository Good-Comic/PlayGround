## 三項改善、風險與驗證

1. **讓最近／最大兩列的位置與按鈕配置更穩定，紀錄變更時指出當前來源與時刻。** 不凍結戰鬥或偷偷保留失效目標。GDD 相容性：**待根代理核實**。風險：固定行高佔空間，提示變更太頻繁。驗證：正常戰鬥、至少五秒意圖間隔下，讓玩家指出要按哪一列及它目前的來源／局內時刻；記錄自然誤認與取消，不刻意挨打。
2. **反擊成功回饋加入簡短來源類型與該筆局內時刻。** 例如讓「16人反擊」更容易與剛讀過的紀錄對照；仍不宣稱命中。GDD 相容性：**待核實**。風險：提示變長、把歷史紀錄誤當持續追蹤。驗證：來源紀錄正常更新後，測玩家能否說出已下令的是哪筆，並區分命令、目前目標與歷史方向；以正常可見資訊為限。
3. **查看後可試驗短暫的來源描邊，外觀明確不同於集火環標。** 只對正常可見來源，幫助在屋頂與聚團中定位；不派兵。GDD 相容性：**待核實**。風險：玩家誤認已下令、標記雜亂或洩漏霧中資訊。驗證：查看後問目前是否已派令及來源在哪，觀察是否誤點反擊或重複查看，同時核對不可見來源不被額外揭露。

這輪支持「查看與反擊可在可見 UI 分開理解；反擊能形成明確的當前選兵集火指令」。它同時留下紀錄快速更新時的來源對照疑問。沒有取消分支、手動後令、精確命中、長期遊玩或真人資料；不能宣稱勝率改善、最佳策略或技術保護全數通過。

**有條件願意再玩，立即重開意願仍偏低。** 我對反擊是否真的成為攻擊命令更有把握，但這輪仍在取得新戰鬥回饋前失守。會想在正常遊玩中縮短查找與決策的拖延，這是 AI 角色想法，不是已驗證打法或真人留存證據。
