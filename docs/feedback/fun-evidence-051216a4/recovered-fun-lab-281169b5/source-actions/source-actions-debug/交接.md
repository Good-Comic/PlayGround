## 根代理 QA 介面

原安裝入口為 `installCoreDamageReadback(g, ui, renderer)`；保留 `#core-damage-readback`，根代理可讀其 `innerText`。兩行的既有節點不重建；來源不可辨識時隱藏控制並清空文字、tooltip 與 aria 標籤。

按鈕 selector：`#core-damage-readback button[data-source-kind="last"][data-source-action="view"]`。`source-kind` 為 `last` 或 `peak`；`source-action` 為 `view` 或 `attack`。按鈕同時帶兩個屬性，不是父層帶 kind。當最大值與最近值的顯示精度相同時，整個最大行與控制隱藏。

`ui.coreDamageReadback.view()` 的頂層為最近事件，`.peak` 為最大事件。兩者各有 `loss`、`at`、`sourceId`、`name`、`direction`、`token`；token 是 frozen 空物件，無世界／單位參照。數字與字串均為副本，不可改到內部事件。

可直接測試的 API：

- `captureAction(kind, renderedToken, action, {blocked=false})`：必須給目前顯示行的那次 token；成功回傳 `{ok:true, lease, count}`。lease 同樣是 frozen 空物件。拒絕回傳 `{ok:false, reason:'changed'|'select'|'unavailable', count?}`。
- `validateAction(lease, {blocked=false})`：合法回傳 `{ok:true}`；失效回傳 `{ok:false, reason:'changed'}` 並永久取消這份憑證。
- `activateAction(lease, {blocked=false, canPoint, viewport})`：先重驗並消耗憑證，再直接沿 manual-target API 執行一次。攻擊成功為 `{ok:true,count,targetId,type}`；查看成功為 `{ok:true,targetId,spot}`。失敗可能是 `changed`、`unavailable`、`unseen`、`select` 或 `noPoint`，不退回移動、不改選兵、不重新發送。原生命令／相機例外原樣傳出，憑證仍已消耗。
- `cancelAction(lease)`：取消單份憑證，回傳 WeakMap 刪除結果。
- `update()`：同步來源／事件／選兵／模式／語言；不做 Canvas 或 native pick 查詢。
- `diagnostics()`：`events`、`faults`、`lastLoss` 與 UI 額外的 `uiFaults`。

真實滑鼠啟用須有 pointerdown 然後 native click；鍵盤以非 repeat Enter 或 Space 的 keydown 捕捉，保留原生 click 與 Tab 導航。不提供沒有新 pointer／key gesture 的 click 自動捕捉。blur、pointercancel、視窗失焦、其他軍事鍵、視窗外部 pointerdown／pointerup、行隱藏或上下文變更都取消。按鍵仍壓住但來源消失時，重複鍵也不會漏成全域暫停。

Canvas 可用點嚴格要求 CSS 視口內且 `document.elementFromPoint(p.x,p.y)===renderer.canvas`。只有明確啟用會查詢；查看只設定原生相機目標。英雄直控停用兩種操作；零選兵可查看，混選與非正式戰士不能反擊。開啟戰線面板也停用此入口，避免混入另一項未完成操作。
