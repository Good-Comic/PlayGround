2. **總管生產診斷，中。** 372.981 秒 [馬廄規劃](screen-0025.json) 顯示自動啟用、預留零、佇列上限 1、目標 200，但狀態仍是「等待資源／保留預算」，頂部有 350 食／170 金。之後 [馬廄](screen-0027.json) 公開成本為 65 食／20 金，且手動排兵成功。通用狀態不易讓我知道是哪個條件在限制，導致重開與比對。這只證明診斷不夠明確，沒有證明自動化停擺或存在 bug。

3. **鏡頭與移動單位選取成本，中。** 270.968 秒 [城區已離開視野](screen-0017.png)；595–637 秒一連串點村民選到 [房屋](screen-0038.json)、[城心](screen-0040.json)、[空地](screen-0041.json)，[框選](screen-0042.json) 才成功。我的長平移與過期座標有直接責任；選取命中是否有缺陷未證實。但這些成本確實吃掉有限操作預算。暫時性控制項標記失效則是測試介面問題，與遊戲本身分列。
