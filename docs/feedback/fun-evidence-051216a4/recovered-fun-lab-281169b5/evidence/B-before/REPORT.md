## 三項改善、風險與驗證

1. **總管常用規劃放第一屏，保持儲存／關閉可見。** 將採集偏好、村民目標、房屋目標、軍事方案與升時代提案集中，完整建築表格留進階入口。GDD 相容性：**待根代理核實**；玩家未讀完整 GDD，建議保留手動命令優先與既有成本能力。風險：簡化預設可能讓玩家誤解自動生產是否啟用，小螢幕也可能擁擠。驗證：新休閒玩家完成三房一馬廄與升時代先詢問，對照意圖數、牆鐘、誤啟動及預留資源理解，不改難度。
2. **強化城心受攻方向、衝車威脅與援護城心的命令回饋。** 僅使用已看見或已發生的攻擊資訊，顯示近期傷害來源類型及這次援護的目標／護衛狀態。GDD 相容性：**待核實**，先以資訊呈現測試，不加自動戰鬥能力。風險：過密告警、誤揭迷霧情報。驗證：重播可見第四波情境，測辨識方向時間、一次回防的誤點與告警忽略率，核對霧區資訊不外洩。
3. **選卡預設突出候選、已持效果與短文明提示，完整圖譜由明確入口開啟。** GDD 相容性：**待核實**；不改抽卡、效果或可查內容。風險：長線構築玩家可能較難發現關聯。驗證：相同三張候選比較選卡理由、代價理解、決策時間、誤解、圖鑑使用率與反悔，不只追求最快點選。
