# 城心實際受傷回饋與 A 聚焦續測

第四個實際切片把已發生的城心 HP 損失、可確認來源與事件時間放進既有戰鬥 HUD。來源 `955fceaadb781d9128a857636c0f20a4830ccc12`。使用者最新測試指令要求報告與交接一律臺灣正體中文，本輪整理文件已修正；原始封存 bytes、SHA、識別符與遊戲四語保持。

## 實際行為

- 原生 `applyDamage` 完整呼叫一次後，計算 `max(0, HP前) − max(0, HP後)`。護甲及護盾處理沿原生；完全吸收不報失血，過量致命傷只計剩餘 HP。
- 只記自己的城心真實失血；敵人瞄準、attack 狀態、修復或其他單位受傷不產生紀錄。
- 來源須在受傷時與顯示時都存活、屬目前世界並正式可見。失視野同一 UI 更新就移除身分／方位，此筆不重新追蹤。
- 箭頭只用於受傷當時可見近戰攻擊者的原生畫面投影方位。投射物與區域命中不猜發射來向；來源未知仍能顯示自己的失血。
- 新局、讀檔、換世界及獎勵／結算清除暫態回饋。不增加存檔規則、命令、警示聲、鏡頭、選敵或傷害。

改動在 `js/core-damage-readback.js`、`js/main.js`、四語字串與單一 HUD 樣式。未改 `Game.js` 的傷害分支。觀察層自己的錯誤不攔截原生致命傷；原生錯誤仍原樣拋出。

資訊放在原戰鬥列、援護入口旁，而非擴高左上城心卡片：左上卡片在窄視窗隱藏，擴高還會碰到戰旗面板。四語／四視口實際檢查此位置與命令列可用。

同一原封快照、原 PROFILE、獨立瀏覽器，正常一倍速，沒有資源／HP／RNG 注入。不是全新十波、不是盲測，A 保有自己的既有經驗。Continue 到結算觀察約 79.158 秒；累計度過 3 波、75 擊殺、3,660 採集、9:00 統治時間，不能把累計值都算本段新增。

A 有條件願再玩，沒有可比較的新數字評分；無聊時刻證據零項，沒有虛構三項。操作比 PROFILE 的理想反應慢，含閱讀、看圖、模型與工具往返。結果支持因果資訊更可讀，尚不支持整體更好玩、救城、留存或勝率提升。第一閉環其他角色與中斷 C 證據沒有被這份單例取代。

## 成本與限制

[純 API 微量測](core-damage/core-damage-cost.json)在100／200實體各做 ABBA，800次暖機＋5,000次樣本。每次前重設城心HP與清視覺粒子，直接原生命中並做一次純資料格式化；這是隔離成本的控制微量測，沒有 AI／繪圖／模擬更新，不能當 FPS 或自然遊玩。四個 After 各5800筆事件、零觀察錯誤，單次原生傷害＋觀察／格式化 P95 約0.0040–0.0056毫秒；不等於實戰幀尾或無洩漏。

既有 RALLY 100／200及 ABBA 結果仍各自固定在其來源；沒有拿舊版 FPS 宣稱955長測通過。SwiftShader是CPU軟體繪圖，持續大量存活、長時間、實體GPU、真人樂趣／聽感及自然十波／NG+仍未通過或未驗。嚴格Save/Load RNG表示差異FAIL仍保留。

下一項已獲 Director 裁決可做「本波已記錄最大單次實損」：只對本次載入後已觀察的本波原始 HP 差取 max，不做來源排行榜、DPS或自動選敵，last/max各自遵守視野。A 此次是小傷到大傷，尚未自然證明大傷被小傷取代，因此這是待驗改善假說。所有內容仍只在獨立分支，不公開部署。
