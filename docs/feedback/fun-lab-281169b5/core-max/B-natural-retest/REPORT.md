## 三項改善、風險與驗證

1. **在時刻旁提供短而明確的時間基準。** 例如正常提示內說明是事件的局內時刻，以及最大只記本次載入後。GDD 相容性：**待根代理核實**。風險：增加閱讀量，與短行節奏衝突。驗證：只給可見畫面，請新休閒玩家解釋 8:30 是事件時刻還是多久以前、是否包含載入前，記錄誤解，不要求背數字。
2. **保留「受傷時」與來源未確認的措辭，測試來源身分和目前確認狀態能否更容易區分。** GDD 相容性：**待核實**。風險：多一層狀態造成擁擠，或讓玩家誤認可追蹤霧中來源。驗證：正常可見來源出現／不再可確認時，測玩家是否把類型誤當同一敵人、把歷史箭頭當即時位置；核對不提供霧中身分。
3. **讓下令後的「移動／攻擊目標」摘要短暫更醒目。** 保留玩家手動選擇與目前摘要，先測自然誤點能否更快被注意。人工集火標示本輪未評估，需先核對現況。GDD 相容性：**待核實**。風險：正常移動也頻繁閃動、分散戰鬥注意力。驗證：原生點選測試中，記錄自然落差的察覺與補救意圖數；不故意送兵、不自動改令，也不只以勝敗判斷。
