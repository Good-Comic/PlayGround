# 直控待命不再被射程外自動目標拖住

## 玩家差異與原因

上一輪已防止超距命中，但留下相鄰情況：自動目標離開射程後，原評分的黏著加分仍會優先選它；最終距離檢查雖正確拒絕攻擊，卻也讓英雄忽略身旁可命中的敵人。

已以受控狀態重現：近敵距離1.1、既有自動目標距離1.4、合法距離1.16，舊版兩者都不受傷。這是相鄰缺陷的重現，不宣稱已在既有真人場次觀察到該精確配置。

新版直控待命時，自動選敵先排除不在既有攻擊距離內的候選，再沿用原有評分，因此會改打身旁合法近敵。**人工指定目標仍保留最高優先**：玩家指定遠敵時不自行改打其他人，仍須玩家接近；沒有恢復超距命中。

## 修改範圍

- `js/targeting.js`：選擇性eligible篩選只作用於自動候選；原人工目標保留分支仍優先。未提供篩選時行為相同。
- `js/game.js`：acquireTarget轉交可選篩選；只有updateHeroDirect啟用既有攻擊距離條件。最後仍驗證距離，避免人工遠目標繞過。
- 其他部隊、敵軍、戰術命令沒有傳入此篩選；不改原評分、克制、黏著數值、移動、射程、傷害、視野或RNG。沒有新增全局掃描，只在既有候選迴圈加入可選檢查。
