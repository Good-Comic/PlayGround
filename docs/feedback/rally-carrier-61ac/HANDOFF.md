# 可擊破戰旗：受控驗證完成，正式戰役驗證中

依使用者最新語言要求，本回報採臺灣正體中文。原始識別符、測試輸出與四語遊戲介面保留原文。

## 實際遊戲改善

承接拖曳戰線、分層列陣及原生撤退操作，新增依GDD §6.1運作的可擊破旗手：玩家能選擇集中火力，解除敵軍支援。原版RALLY只是永久套用整波攻速1.1倍率，沒有旗手、距離或到期限制。

新局優先由波次表裡原有精銳擔任旗手；沒有精銳時才選同類最低威脅步兵。依完整波次表選類型，等待該組原生生成，不額外增兵、不提高旗手生命，也不改16文明事件表。中國沒有RALLY；法蘭克第5波、不列顛第9波及其他文明指定波次沿用正式安排。

旗手周圍4格敵軍獲得10%攻速，從正式事件啟動起持續15模擬秒。旗手死亡或改變陣營立即解除；不轉派替代旗手。Boss不接受此加成，原有狂暴與其他事件規則保留。既有攻擊冷卻倒數不重設，只影響原生下一次冷卻計算。

旗幟與可選擇顯示的範圍圈使用現有Canvas 2D，依單位深度排序；不顯示未看見的旗手，按鈕也無法聚焦迷霧中的位置。範圍圈只在懸停／選取旗手時顯示，沒有加入粒子RNG或外部資產。

## 暫停、存讀檔與舊版本

到期時間使用waveClock，沒有現實計時器；暫停、選卡和結算沿用原生模擬停止。Save/Load保存旗手ID、類型、啟動及到期時間，不增加新的15秒。已有死亡旗手不復活。

歷史RALLY存檔沒有旗手資料時，保留該波原行為，明確顯示舊存檔說明，不猜測歷史旗手或重啟計時；後續新波使用新規則。這是相容性限制，不能宣稱舊波全域加成也已追溯修復。

補充回歸曾重現新原型的殘兵全域倍率跨波次殘留；已改由原生事件套用入口清除舊全域欄位，動態範圍由獨立Adapter計算。Node失敗紀錄完整保留。另一個實際鍵盤問題是Tab／Shift+Tab在新按鈕上誤觸英雄直控；原2項FAIL已修正，最後6項鍵盤測試通過。

## 性能：保留限制

Chrome154.0.8037.57、Linux、AMD EPYC9V74、四CPU配額、ANGLE Vulkan SwiftShader軟體繪圖。序列執行；同種子42，初始100／200總單位，正常AI、碰撞、傷害、可見性及繪圖；自動生產同樣關閉以固定生成預算。旗手是正式130HP精銳；僅在性能夾具安排原生生成組、合法位置及初始waveClock20，不是自然戰役。所有補入敵軍皆套用原生事件入口。
