# 總管確認時保留未套用草稿

## 玩家差異與根因

延續既有玩家 B「時代確認需要反推」及上一輪費用預覽改善。舊版點確認呼叫 `render()` 重建整個表單，數值全部回到已套用設定，導致玩家先編輯的採集比例、資源預留與生產設定丟失；上一輪只警告這項限制，本輪直接修正。

`js/steward-ui.js` 在確認前擷取具名欄位的值與勾選狀態，重建後還原仍存在且類型相同的控制。新增控制仍用正式預設；已移除控制不錯套到其他欄位。表單原有已套用基線先建立，之後才還原草稿，因此既有「有未套用變更」提示正確保留。

確認成功或失敗都保留草稿；面板開啟時的localechange重建也保留。確認仍僅執行已套用計畫，草稿沒有自動生效，仍須按「儲存規劃」。關閉不儲存仍丟棄草稿，沒有新增跨次開啟／跨存檔草稿機制。

`js/locales.js` 更新四語確認說明，明確表示草稿會保留、需另行儲存。沒有增加按鈕或面板，不修改確認計畫、研究、成本、建造、RNG、尋路或戰鬥規則。
