## 三項效益與剩餘問題

1. **受阻記錄被找到、理解並使用：局部效益成立。** before C 能看到10人集火後只剩4人投入，卻不知道其餘為何自主接敵。after C 第一波162.150秒自然看見「曾回報受阻3人」；首次公開 ref 展開失敗，保留 CONTROL_NOT_VISIBLE_OR_ENABLED，不算讀取成功或玩家能力不足。第四波569.312秒重新點可見細節，0045顯示上次壅塞10人、無法到達0人，且當面說明不是現在仍卡住；本人也正確用歷史語意解讀。584.246秒選組後0046顯示已選10／全軍16、10人待命，594.340秒自行右鍵改令。新入口確實讓他嘗試不同操作，沒有只停在讀文字；它仍未告訴他哪個位置或命令能及時疏通。
2. **原生命令能接續，戰鬥收益仍 UNKNOWN。** 改令後公開文字為9移動1待命，對應0048截圖則為10人移動；保留文字／圖片先後差異，兩者共同支持出現移動狀態，不合併成精確同步人數。616.045秒文字為9待命1自主接敵，626.533秒本人再援護全軍。落點同時 hover 房屋300／300，不能證點到預期純空地；沒有連續位置、抵達、射程或命中證據。歷史提示消失或人數變少也不能當已疏通。第四波仍有18人集火衝車後剩8人集火、8自主、2待命；這一刻各人的原因 UNKNOWN，不能拿先前十人的壅塞記錄直接解釋。危機到有效補救仍未閉合。
3. **可說出的選擇與再試理由保留，經濟困惑未解。** after 自然看見選卡圖譜，能分辨候選、持有、建議與非前置連線，並以快捷鍵選戰地救護、火油罐、狂信再領取；未用篩選／縮放，不評其操作效果，亦不把圖譜功勞全歸本次受阻切片。救援與回防仍是清楚小成果。食物低、木材多、補兵支出與等待難解，防守方案收益仍 UNKNOWN，符合固定 Phase 1 第三問題仍在。再玩意願前後均3／5；after 新增想調整受阻組的具體再試理由，但沒有意願提升或真人留存證據。
