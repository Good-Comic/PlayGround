## 配對與結論

兩種規模均通過初始scene SHA、歷史記錄fixture、模擬RNG及視覺RNG一致；8run無pageerror，沒有raw截斷。此等價僅指起點，非可變dt下的後續完整軌跡。

- 初始100：before兩run平均28.77 FPS，after平均28.70 FPS；兩組P50 33.3／33.3 ms，P95 50.0／50.0 ms。
- 初始200：before兩run平均19.32 FPS，after平均19.62 FPS；兩組P50 50.0／50.0 ms，P95 66.7／66.7 ms。

本短樣本兩版FPS區間重疊、幀時間量級相同；未觀測明顯系統性退步，但不能宣稱已證明長期無回歸。after沒有為維持UI負載改動戰鬥或碰撞，實際可見比例見上表。

## 真實限制

- 每次只30秒，共8run，兩版本各規模僅2重複。
- 初始100/200，暖機及live死亡/刷兵導致量測存活非固定100/200。
- 初始scene/兩RNG等價不表示原生可變dt下後續世界相同。
- CPU throttle為共享容器全體增量；其他既有孤兒程序未終止，無法單獨歸因本遊戲。
- heap包含量測陣列、快取與GC，1Hz可能漏短峰，不判記憶體洩漏。
- 子系統計時inclusive互相巢狀重疊，總時間不可加總。
- 受控歷史orderFailure初始fixture僅測UI負載，不代表自然受阻重現；後續不每幀補寫。

未覆蓋：長時間軍團戰、完整自然十波、實體Windows GPU、校準記憶體洩漏、真人操作或視覺耐受。這些不標PASS。

原始證據：run-01/result.json、raw-{規模}-{Run}.json、scene-{規模}-{Run}.png。瀏覽器已正常關閉，執行exit0。來源複製與SHA見PROVENANCE.json。
