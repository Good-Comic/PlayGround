# Review and continuation protocol

Generate a pending review from an independently fetched pinned PROJECT-STATUS.json using tools/monitor/review_exchange.py --status FILE --out FRESH_DIR. It creates REVIEW-REQUEST.json,REVIEW-RESULT.json,NEXT-DIRECTIVE.json,SUPERVISOR-STATUS.md. No ACCEPTED outcome is generated. Actual external reviewer must inspect remote commit, relevant diff, GDD, test versions/raw failures and Handoff, separate local/integration/online/hardware evidence, then return ACCEPTED/REWORK_REQUIRED/BLOCKED/NEEDS_APPROVAL with evidence. REVIEW_PENDING denotes no executed reviewer. SHA provenance is evidence identity, not proof tests passed or reviewer identity.

Existing agent_dispatch.py remains manual and unchanged. New agent_dispatcher.py is a bounded disconnected planner with adapter argv templates for Codex/Gemini/Claude. It queries source ref and task ownership, enforces one independent continuation branch, read/local-QA/report-only scope, one attempt/one concurrent/zero paid cost, local atomic plan ledger, lock, dedup and audit. It generates a real Recovery inventory before planning and a next-agent prompt. A persistent interrupted lock is never silently stolen; recheck process, source refs, ownership and audit before explicit manual recovery. Duplicate event produces no second audit/Agent execution; reusing ID with different source is rejected. No branch/worktree is created and no CLI is invoked. A generated argv is NOT a dispatch. Supplied review identity is not cryptographically authenticated. Pending review stays pending; even supplied ACCEPTED remains DISPATCH_NOT_CONNECTED.

Current prototype QA catalog: QA-PROGRESS-READ,QA-GAMEPLAY-LOCAL,QA-PAGES-LIVE. It intentionally cannot schedule arbitrary B-E implementations, remote writes, deployment or workflow operations; future scope expansion requires source-pinned requirements/permissions review. Real CLI compatibility, resources/cost caps and independent worktree execution need separate configured authorized adapter; no credentials were requested or external service called. classify_failure accepts structured observed error categories only; unknown messages remain UNKNOWN_FAILURE. No automatic quota retry/account switching is enabled.

Local tests and a manual disconnected plan demonstrate framework behavior, not real Codex→Gemini handoff. HANDOFF_FRAMEWORK_READY / DISPATCH_NOT_CONNECTED; CROSS_AGENT_HANDOFF_VERIFIED and LIVE_CODEX_STREAM_VERIFIED are NOT claimed. Continue gameplay independently of this pending external review.
